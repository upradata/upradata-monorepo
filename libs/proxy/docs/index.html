Upra-Data Monorepo

A comprehensive monorepo containing libraries, applications, and tools built with TypeScript, using pnpm workspaces and Turborepo.

Getting Started

Prerequisites

  • Node.js 20.x or higher (use .nvmrc with nvm)
  • pnpm 9.x or higher

Install

pnpm install

Development

# Lint all packages
pnpm lint
pnpm lint:fix

# Type check
pnpm typecheck

# Test
pnpm test
pnpm test:coverage

# Build
pnpm build

# Format code
pnpm format

Workspace Structure

Monorepo(new)/
├── libs/           # Core libraries (@upradata/*)
├── apps/           # Applications
├── tools/          # CLI tools and build utilities
└── configs/        # Shared configuration packages
